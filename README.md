
# 🎤 Speech-to-Text Application

A simple and interactive **Speech-to-Text Application** developed using Python, OpenAI Whisper, and Gradio. The application converts spoken audio into written text automatically and can be run easily in **Google Colab**.

## 🚀 Project Overview

The Speech-to-Text Application uses the **Whisper speech recognition model** to process audio and generate accurate text transcriptions. Users can upload an audio file or record their voice using a microphone through the Gradio interface.

## 🎯 Objectives

* Convert speech/audio into text.
* Demonstrate automatic speech recognition using AI.
* Provide a simple and user-friendly interface.
* Process recorded or uploaded audio.
* Run the application easily using Google Colab.

## 🛠️ Technologies Used

* **Python**
* **OpenAI Whisper**
* **Gradio**
* **Speech Recognition**
* **PyTorch**
* **Google Colab**

## ⚙️ How It Works

1. The user uploads an audio file or records speech.
2. The audio is passed to the Whisper model.
3. Whisper analyzes the spoken content.
4. Speech is converted into text.
5. The generated transcription is displayed in the application.

## ✨ Features

* 🎙️ Microphone recording
* 📁 Audio file upload
* 📝 Automatic speech transcription
* 🤖 AI-powered Whisper model
* 🌐 Interactive Gradio interface
* ☁️ Google Colab compatible
